# VRE-412 Design: Full Enrichment Run + Normalization Map

> Enrich all ~1500 articles with structured metadata via Workers AI, integrated into generate-index.mjs.

## Pipeline Change

```
Current:  sitemap → markdown → buildRecords → embeddings → writeFiles
New:      sitemap → markdown → buildRecords → enrich → embeddings → writeFiles
```

Enrichment runs before embeddings because enrichment output populates `keywords`, which feeds into `embeddingInput()`.

## Enrichment Cache — `src/generated/enrichment-cache.json`

- Shape: `{ recordId: { hash: "abc123...", metadata: { city, neighborhoods, places, dishes, categories, cuisine_type, occasion } } }`
- Same content-hash pattern as the existing embedding cache
- Hash computed from article's cleaned body text
- Cache hit = skip LLM call, reuse stored metadata

## Enrichment Function — `enrichRecords(records)`

- For each record: check cache → if miss, call Workers AI (Llama 3.3 70B) with enrichment prompt + article text (truncated to 4000 chars)
- Sequential processing with 1.5s rate limiting (matches markdown fetch pattern)
- Cache saved every 50 records (crash protection)
- On LLM failure: retry once, then store empty metadata (don't block pipeline)
- Workers AI may return `response` as object or string — handle both (learned from validation script)

## Post-Enrichment

- Attach `metadata` object to each record
- Populate `keywords` array from enrichment: place names + dish names + category names
- This boosts the existing keyword scorer in `scoreDocument()` without code changes

## Normalization Map — `src/generated/normalization-map.json`

- After enrichment: collect all unique values per field (categories, cuisine_type, occasion, dishes)
- Compare against existing normalization map file
- If new values found: single Workers AI call with full value set, ask to cluster synonyms
- Shape: `{ "dinner": "diner", "uit eten": "diner", "Italian": "Italiaans", ... }`
- Apply normalization to records (store both raw and normalized values)
- If no new values: skip LLM clustering pass

## Error Handling

- Individual article failure: log warning, continue with empty metadata
- Normalization LLM failure: log warning, skip normalization (raw values still usable)
- Cache saves every 50 records — progress survives crashes
